Questa API Web fornisce un servizio di gestione per i "roommate", con funzionalità per il controllo dei turni, la gestione delle assegnazioni e la pianificazione delle attività condivise in un appartamento o una casa condivisa.

Funzionalità principali
  -Gestione degli utenti: Aggiungi, aggiorna e rimuovi i "roommate" (coinquilini).
  -Gestione dei turni: Pianifica e gestisci i turni per attività comuni come pulizie, cucina, ecc.
  -Visualizzazione dei turni: Visualizza i turni settimanali, mensili e personalizzati.
  -Notifiche: Invia notifiche per ricordare i turni imminenti.
  -Storico turni: Accedi allo storico dei turni e delle attività svolte.

Tecnologie
  -Backend: .NET, C#
  -Database: SQLite
  -Autenticazione: JWT (JSON Web Tokens)
